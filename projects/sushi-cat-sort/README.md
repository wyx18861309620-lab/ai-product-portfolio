## 项目目标

围绕猫咪主题的 Sort + 养成玩法，结合区域市场与用户偏好，形成可试玩的游戏原型及 IAP / IAA 商业化方案。

## 职责

- **市场与定位**：参与区域市场、竞品和用户偏好调研，分析 Sort 赛道与产品方向。
- **玩法与 UI/UX**：参与排序与养成玩法、游戏界面及交互设计，结合 AIGC 工具支持内容产出。
- **商业化方案**：参与搭建包含 DAU、ARPU、LTV、CAC 的收益预估模型，设计付费点、广告变现与买量思路。
- **开发与验证支持**：参与 Godot 开发及 A/B test 追踪方案设计。
