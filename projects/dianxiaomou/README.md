# 店小谋 · 本地生活商家经营 Agent

**香港大学科研项目 · AI 产品经理 · 2026.09 - 至今**

[在线产品](https://dianxiaomou.com) · [项目补充 PDF](../../assets/project-supplement.pdf) · [返回作品集](../../README.md)

## 项目目标

面向抖音本地生活商家，将账号诊断、定位、经营目标、内容脚本与数据复盘串成完整经营链路，探索 AI 在商家日常经营中的产品化落地。

## 职责

- **产品与交互**：围绕商家经营任务定义功能与使用流程，以可交互原型推进需求定稿，并通过定稿与线上逐项比对完成体验验收。
- **Agent 工作流**：组织工程、评测、运维等 Agent 协作，设计角色指令、交接协议与权限边界；搭建研发、发布、验收、生成四类闭环，加入事实校验与规则兜底。
- **上下文与评测**：构建三层上下文与任务路由，将纠错回写经验库并固化为脚本和门禁；通过历史请求回归与 LLM-as-a-Judge 匿名成对盲评验证输出质量。

## 交付与验证

| 维度 | 结果与口径 |
| --- | --- |
| 产品交付 | 10 天完成 MVP 上线，覆盖账号诊断到数据复盘的经营链路 |
| 回归验证 | 256 条历史请求与基线一致 |
| 内容质量 | 新版账号定位在 36 组匿名成对盲评中获胜 32 组 |
| 发布门禁 | 约 4,800 条自动化测试及浏览器验收；检查并行化后耗时由 10 分 45 秒降至 1 分 40 秒，减少约 **84.5%** |
| 灰度反馈 | **种子商户灰度测试**中，视频曝光量平均提升 **128%** |
