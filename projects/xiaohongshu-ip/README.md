## 项目目标

围绕 Coser 内容建立个人 IP，连接用户兴趣、内容曝光与品牌合作，在有限预算下完成内容生产和合作交付。

## 职责

- **内容与用户洞察**：独立运营小红书等平台账号，持续观察用户偏好、内容表现与平台传播规律。
- **商务合作**：独立对接品牌商家，推进合作沟通、权益确认及交付跟进。
- **资源与执行**：协调模特、场地、道具等资源，完成内容拍摄与合作执行。

## 交付

- **全平台粉丝 1w+**，该口径包含多个平台。
- 累计与 **3-4 个漫展官方**达成置换或付费合作。
- 完成从内容策划、资源整合到执行交付的完整流程。
